### Estudo de Caso de UX: Portal do CIEE

Projeto prático de UX (Experiência de Usuário) onde realizamos um estudo de caso completo no site do CIEE, englobando desde a etapa de pesquisa com usuários e análise estatística até a criação e validação de protótipos de alta fidelidade para propor melhorias de usabilidade.

### Estudo

- O objetivo geral e cronograma do projeto podem ser acessados respectivamente em: [Projeto CIEE](./1-ProjetoCIEE-IHC.pdf) e [Cronograma](./Cronograma.md);
- As perguntas da pesquisa feita com os usuários pode ser acessada em: [Pesquisa de Usabilidade e UX](./Pesquisa.pdf);
- A análise feita a partir da pesquisa e as possíveis melhorias selecionadas para a prototipação estão disponíveis em: [Análise dos dados](./2-AnáliseDosDados.pdf);
- A atividade a ser realizada no protótipo é: Usuário deve acessar a área de vagas e se inscrever no processo do Centro de Música de Brasília, e, em seguida, acessar seu perfil e visualizar os processos em que se inscreveu. O protótipo de alta fidelidade desenvolvido para validação está disponível em [Protótipo](https://www.figma.com/proto/9oqEDcg8aMmU6wOPgxA6Dd/CIEE?node-id=6-50&p=f&t=GSS9SsNaGQtyeldA-8&scaling=min-zoom&content-scaling=fixed&page-id=0%3A1&starting-point-node-id=6%3A50&hide-ui=1);
- Os resultados das entrevistas com os usuários para validação do protótipo está disponível em: [Resultados](./3-Resultados.pdf).
